# 良子饭店 · 扫码点餐微信小程序

![良子饭店门店](docs/images/storefront.jpg)

一款专为**良子饭店**（济宁私房菜）定制的微信扫码点餐小程序。顾客扫桌上二维码即可浏览菜单、下单并微信支付；员工通过**同一小程序**登录管理端完成订单处理、菜品管理与经营配置，无需电脑、无需小票打印。

## 功能特性

**顾客端**
- 扫码绑桌：每桌独立二维码，自动识别桌号进入点餐
- 菜单浏览：分类浏览、固定菜品 + 规格选择
- 下单支付：先付后吃，微信支付；堂食与外卖两种模式
- 订单跟踪：实时查看点单与上菜进度

**管理端**（与顾客端同一小程序，4 个 Tab）
| Tab | 功能 |
|-----|------|
| 堂食 | 按桌号管理订单、逐菜标记上菜 |
| 外卖 | 配送订单管理 |
| 菜品 | 上架 / 售罄 / 下架三态切换、快速改价、新增 / 编辑 / 删除 |
| 经营 | 桌台二维码、员工管理、配送设置、营业数据 |

其他：售罄菜品每日 00:00 自动恢复上架；支持 10 张桌（编号 1~10）；自有员工配送。

## 技术栈

- **前端**：uni-app（Vue2）+ uView UI 2.x，编译为微信小程序
- **后端**：Node.js + Koa2
- **存储**：MySQL（11 张表）+ Redis
- **认证**：JWT（顾客端与员工端分离过期时间）
- **支付**：微信支付（后端已实现 mock，待接入真实商户号）

## 本地运行

**环境要求**：Node.js、MySQL（127.0.0.1:3306）、Redis（127.0.0.1:6379）

```bash
# 1. 初始化数据库
mysql -uroot -p < server/sql/init.sql

# 2. 配置后端环境变量
cd server
cp .env.example .env      # 按需修改数据库账号等
npm install
node app.js               # 服务启动于 localhost:3000

# 3. 运行前端
# 用 HBuilderX 打开 sky-fandian_1/，运行到微信开发者工具
```

> 前端仅支持小程序编译（微信开发者工具），不支持 H5 浏览器编译。

**管理端默认账号**：`admin / admin123`（上线前请务必修改）。
